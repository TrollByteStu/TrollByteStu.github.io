StateTree Course 04 : Global Tasks & Evaluators

Some tasks can run on the StateTree No matter what State you are in, and if you need some code constantly calculate something like percentage of HP from MaxPH or something, you can turn this into an evaluator and run it centrally, so all states have easy access to this info, this is called an evaluator.
