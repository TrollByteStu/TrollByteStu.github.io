StateTree Dialogue 09 : Basic Setup and Widget Display

Switching from a system that handles the logic on an NPC, using State Trees we now build a simple elegant system for complex dialogues with StateTree.

If you want complex character to speak with, with multiple lines of conversation that switched based on what you have asked or which quests you have finished, this will make making and managing those dialogues WAY easier.. For big RPGs this is amust, but several other games could surely use it as well.
