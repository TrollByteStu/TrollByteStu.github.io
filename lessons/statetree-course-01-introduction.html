StateTree Course 01 : Introduction

The new way of running NPCs in Unreal is the new StateTree System. It reminds you a lot of the old behavior tree system. If you are newer than that then think that your NPC is in a state "Bored"/"Angry"/"Scared". You write the rules of what it does, thee are called Tasks. You write the rules of when change into Bored/Hungry/Angry/Wounded or whatever is relevant for your NPC, these are called Transitions.

The whole thing is arranged in logic Tree structure, allowing you to setup basic states like "InCombat" and substates like "WinningCombat" or "LoosingCombat" and arrange the rules so you have control of how it acts during each.

The main course is very theoretically heavy, so I advice you start with a short tutorial by Gorka, showing a short real use of the system. So when the theory how to use a thing in 4 different ways, it is not just a new name to you, you have seen it actually work. It helped me, it might help you.

Gorka Spends 15 minutes showing you how to set up a StateTree. The rest of the course is very theoretical, so if you haven't seen or tried a small example first, you might get lost in explaining what each button does.. I recommend seeing/doing this first before starting the course.

This is the first video in the StateTree Course. It explain what it is how works, and shows you what each button and tab does on the main interface.
