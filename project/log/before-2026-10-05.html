The pitch, and where we started

Before 2026 Oct 5

The pitch for BOILERHEART II: Cranky Engines, and a new Unreal project built on Epic's Game Animation Sample.

What we had

  • The pitch. BOILERHEART II: Cranky Engines grew out of the earlier pitch BOILERHEART: a crew living inside a thinking war-tank raised on poetry and opera.
  • A new project in Unreal Engine 5.8, built on Epic's Game Animation Sample (GASP), in Blueprints, with a finished, good-looking character from day one.
  • Climbing components added on top of GASP, the start of "climb anywhere".
  • Version control in Diversion, after GitHub timed out eight times in a row on this project.
