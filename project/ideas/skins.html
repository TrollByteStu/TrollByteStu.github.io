Skins and faction looks

Planned First thought of: 2026 Oct 17

One master material for every piece, with a skin number per piece. Factions later become colour palettes over a shared texture library.

Every building piece uses one master material, and each placed piece remembers a skin number. Later, each faction gets its own palette over a shared library of textures and material functions, so a new faction is mostly new colours and a few new textures, not a new set of models.
